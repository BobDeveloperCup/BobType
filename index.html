O que é o BobType?

Uma ferramenta avançada para automatizar o preenchimento de redações e textos de forma inteligente e segura através de comunicação via abas.

Como Usar (Webhook / Bookmarklet)

  1. Copie o código do webhook abaixo.
  2. Crie um novo favorito no seu navegador.
  3. Cole o código na URL do favorito.
  4. Abra a página de destino e clique no favorito para conectar o painel.
